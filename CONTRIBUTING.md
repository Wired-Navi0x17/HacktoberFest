# 🤝 Contributing to DevSphere HacktoberFest

Thank you for participating in DevSphere HacktoberFest!

### Quick Steps:
1. Fork or clone the repository.
2. Create your personal branch: `git checkout -b feature/<your-username>`.
3. Add a profile or project file under `participants/`.
4. Submit a Pull Request.

> **Pro Tip**: Always use Git version control—never zip folders over WhatsApp or Google Drive! 😉
