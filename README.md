# 🎃 DevSphere — HacktoberFest 2026

Welcome to the **DevSphere HacktoberFest** repository!

This repository is designed for hands-on learning during our live Git & GitHub workshop.

---

## 🚀 Getting Started

1. **Clone this repository**:
   ```bash
   git clone git@github.com:Wired-Navi0x17/HacktoberFest.git
   cd HacktoberFest
   ```

2. **Create a new branch**:
   ```bash
   git checkout -b feature/your-name-profile
   ```

3. **Make your changes & commit**:
   ```bash
   git add .
   git commit -m "feat: add my first contribution"
   ```

4. **Push & Open a Pull Request**:
   ```bash
   git push -u origin feature/your-name-profile
   ```

---

## 📜 Rules of the Game
- Write clean code
- Meaningful commit messages (no more `final_actually_done_v2`!)
- Happy Hacking! 💻✨
