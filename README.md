### 🎀 ₊˚ Quick Start / How to Contribute

```bash
# 1. Clone this repository (bring it to your machine!)
git clone git@github.com:Wired-Navi0x17/HacktoberFest.git
cd HacktoberFest

# 2. Create your own cute branch
git checkout -b feature/my-first-edit

# 3. Open foo.py and tweak a variable or add something cool
python foo.py

# 4. Stage & Commit your changes
git add foo.py
git commit -m "feat: updated coffee count and vibes"

# 5. Push to GitHub!
git push origin feature/my-first-edit
```

### 🍰 ₊˚ Git Cheatsheet (No-Panic Edition)

| Cute Command | What it actually does |
| :--- | :--- |
| `git status` | Shows you what changed without breaking anything (your best friend!) 🔍 |
| `git diff` | Peek at the exact lines you added or deleted 📝 |
| `git add <file>` | Tells Git: *"I want to pack this file for the next snapshot"* 📦 |
| `git commit -m "..."` | Saves the snapshot with a cute little description 📸 |
| `git push` | Sends your changes flying to GitHub 🚀✨ |
